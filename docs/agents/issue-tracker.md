## Issue Tracker

Issues and specs are tracked as local markdown files under `.scratch/` in the repo root.

### File Naming

- Specs: `.scratch/spec-<slug>.md`
- Tickets: `.scratch/ticket-<number>-<slug>.md`
- Bug reports: `.scratch/bug-<number>-<slug>.md`

### Workflow

1. Create a spec or ticket file under `.scratch/`.
2. Reference it from commits and PR descriptions.
3. Close by adding a `## Closed` section with a date and reason.
