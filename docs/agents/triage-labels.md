## Triage Labels

Five canonical triage roles used for issue classification:

| Label | Description |
|:---|:---|
| `needs-triage` | New issue, not yet classified |
| `needs-info` | Blocked on information from the reporter |
| `ready-for-agent` | Actionable by an AI coding agent |
| `ready-for-human` | Requires human judgment or access |
| `wontfix` | Deliberately declined |
